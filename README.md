# 🛒 E-Commerce SQL Data Analysis

## 📌 Project Overview

This project focuses on analyzing an E-Commerce database using SQL Server. The project includes database tables, customer and product information, orders, and SQL queries used to extract meaningful business insights.

## 🛠️ Tools & Technologies

* SQL Server
* SQL Server Management Studio (SSMS)
* SQL
